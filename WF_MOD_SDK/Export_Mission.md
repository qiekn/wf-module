# 从 WF MOD SDK 1.4.5 导出关卡 | 将地图导入到自定义 WARFACE 客户端（服务器）

在您创建自己的地图或修改现有地图后，您肯定会想在上面游玩并检查其是否正常运行，毕竟编辑器本身由于其特性并不能完全实现这一点，您最多只能在游戏模式中简单地走一遍。本文将教您如何将地图导入 WARFACE，以便您可以进行游戏、射击、激活您的彩蛋等。

## 导出到客户端的流程

首先，您需要获取地图文件。由于 WARFACE 不支持引擎的 CRY 文件，它需要包含地图信息的 PAK 存档。获取这些文件的步骤如下：

1. 打开编辑器并启动您要导入到游戏中的地图；
2. 在顶部菜单栏中，转到 \[File —> Generate Surface Texture\]，选择您的地形纹理尺寸（设置为 4096x4096，不要纠结，因为更大也不行），然后勾选 \[High Quality\]，在 \[Terrain Color Multiplier\] 中设置值为 \[8\]。此外，如果您希望获得更高质量的阴影、地形纹理以及整体画面改进，可以勾选 \[Calculate Terrain Sky Accessibility\]，但请注意，后续处理将大幅延慢导出过程。点击 \[Ok\] 等待过程完成；
3. 确保地图中一切正常且没有遗漏后，转到顶部菜单栏，依次点击 \[File —> Save\] 和 \[File —> Export to Engine\]；
4. 完成后可关闭编辑器。

在您的地图文件夹中，您需要的文件如下：

1. 存档 \[level.pak\] — 主要存档，几乎所有的关卡信息都保存在其中；
2. 存档 \[terraintexture.pak\] — 包含地形纹理数据，这些数据在编辑器中的“Generate Surface Textures”中保存（经发现，对于 WARFACE 该文件其实并非必须，但开发者仍然将其包括在内，原因不明）；
3. 文件 \[filelist.xml\] — 保存关键信息（MD5 哈希和文件大小）的文件 (\[level.pak\], \[Level_Name.dds\] 和 \[Level_Name.xml\])，在“Export to Engine”过程中生成（用于客户端保护和服务器启动地图）；
4. 文件 \[tags.txt\] — 当您在编辑器中创建摄像机位置时（CTRL + F1-F12），这些位置会保存在此文件中（即使没有这样的摄像机，该文件也会生成）；
5. 文件 \[Level_Name.dds\] — 您关卡的迷你地图图像（仅在您生成了迷你地图时具有）。有关生成迷你地图的详细说明，请参见 "Create_MiniMap"；
6. 文件 \[Level_Name.xml\] — 此文件定义了迷你地图的显示信息（仅在您生成了迷你地图时具有）。有关生成迷你地图的详细说明，请参见 "Create_MiniMap"；

此外，您还需要自己创建几个文件：

7. 文件 \[level.cfg\] — 配置文件，包含在启动该地图时执行的命令（如果您没有此类想法，则可以不创建）。示例请参见截图；

上述所有文件应存放在 \[Game/Levels/路径*到*您的*地图/您的*地图/\] 中，注意 \[路径*到*您的*地图\] 应与您在编辑器中保存时的地图位置一致。除了 \[level.pak\] 和 \[terraintexture.pak\] 之外，您必须将所有文件放置在 PAK 存档中的同一路径下。例如，\[Z_Levels.pak/Levels/路径*到*您的*地图/您的\_地图/submissionconfig.xml\])。将 \[level.pak\] 和 \[terraintexture.pak\] 直接放入客户端的 \[Levels\] 文件夹中。您的地图 PAK 存档需要放在游戏客户端的 \[Game\] 文件夹中。关于如何创建 PAK 存档的说明，请参见 "Create_PAK"。

请注意！您的存档文件应按字母顺序放置在 \[Game\] 文件夹的底部，因此将存档命名以字母 \[Z\] 开头。游戏会在字母序列的最后加载这些存档，优先级更高，如果您的文件与基础客户端的文件有重叠。

到此，地图添加到客户端的过程已完成，您甚至可以使用 MVM 启动它，录制一些漂亮的视频 ;)

## 导出到服务器的过程

要在您的服务器（模拟器）上添加地图，您还需进行一些操作。具体为：

1. 创建文件 \[Level_Name.xml\]，该文件将存放在客户端和服务器的路径中 — [/libs/missions/\]，在服务器（模拟器）中路径可能不同，但肯定包含该路径段。在此文件中，您需要写入地图参数，以便服务器知道：地图名称、启动模式、其唯一 UID、是否可在游戏中使用、是否可以在公会战中启动、可用频道、其本地化信息、图标及奖励，以及应启动的地图。以下截图展示了文件的示例。对于 PvP 和 PvE，文件的格式不同，但它们的核心思想是相同的 — 向游戏提供启动、结束地图的指令，并在客户端中显示地图。有关创建该文件的说明，请参见 "Create_Server_XML"；
2. 将地图添加到快速游戏的轮换中。在客户端和服务器中，快速游戏的轮换由文件 \[quickplay_maps.xml\] 定义。这里填写我们先前创建的文件名称及其模式所在的部分。
3. 同样，将您创建和获取的所有文件以普通文件而非存档的形式移入服务器（模拟器）文件夹中。在模拟器中，查找 \[Levels\] 文件夹，并添加与客户端相同路径的地图文件。

## 总结

至此，地图导入游戏的过程已完成。您可以在其上游玩，或继续进一步编辑，深入研究地图创建并添加新功能。
